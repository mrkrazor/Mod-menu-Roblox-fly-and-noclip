# Krazor // Universal Admin Core

A minimalist, highly optimized cross-platform administration menu for Roblox environment testing. Designed to work flawlessly across PC, Laptops, and Mobile devices with a unified dark UI interface.

## 🛠 Features

* **Stealth Flight Physics:** Uses precision CFrame positioning instead of outdated physical velocity objects to minimize detection flags.
* **Cross-Platform Flight Engine:** Supports native hardware detection (W/A/S/D + E/Q for PC/Laptops, and screen joystick + UI buttons for Mobile users).
* **Noclip Mode:** Bypasses local part collisions frame-by-frame for map exploration.
* **Dynamic Speed Adjuster:** Hot-swap your flying speed using immediate layout triggers.
* **Compact Dark UI:** Drag-and-drop structural framework with modern cyberpunk styling.

## ⌨ Controls Matrix

| Device Type | Navigation Control | Fly Upward | Fly Downward |
| :--- | :--- | :--- | :--- |
| **PC & Laptop** | `W` `A` `S` `D` Keys | Hold `E` Key | Hold `Q` Key |
| **Mobile & Touch** | On-screen Joystick | Press `▲ UP` Button | Press `▼ DOWN` Button |

1. Copy the full script core from `krazor.lua`.
